Server From Scratch

An HTTP/1.1 server built directly on raw sockets — the request parser, router, and response serializer are all hand-written. No Boost.Asio, no libuv, no HTTP library underneath. This page is being served by it right now.

Requests are relative — this only works when the page is actually served by SFS (i.e. you're viewing this at http://localhost:<port>).

architecture

Thread pool

One acceptor thread, a fixed pool of workers. Each connection is enqueued and picked up by whichever worker is free — no thread spawned per request.

Custom parser

Reads the request line, headers, and body straight off the socket, with bounded buffers so a malformed request can't exhaust memory.

Path-param router

Routes like /users/:id are matched segment by segment. Wrong method on a known path returns 405, not a generic 404.

Hardened file server

Static files are resolved through a canonical-path check, so directory-traversal attempts outside the public root are rejected.

request lifecycle

accept() → enqueue() → worker thread → Router::dispatch() → Handler → Response::serialize() → send()

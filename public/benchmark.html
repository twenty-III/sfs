How fast is it, really?

This fires real HTTP requests from your browser at SFS and measures wall-clock latency end-to-end — TCP handshake, request, response — the same thing a real client experiences. No server-side instrumentation, no fake numbers.

configure

idle

Leave target origin blank to benchmark this server (recommended — same-origin, no CORS issues). Testing a different origin only works if that server sends Access-Control-Allow-Origin headers. Also: browsers cap concurrent connections per origin (~6 for HTTP/1.1), so very high concurrency values here won't reflect true server-side parallelism — for finding the server's actual ceiling, run wrk or ab from a terminal instead. This is great for demoing correctness and realistic load, not for finding the absolute limit.

Deployed on a free host like Render? The first request after 15 minutes of inactivity can take 30-60 seconds (cold start) — hit /ping once yourself before running a benchmark, or that single request will dominate every chart below.
